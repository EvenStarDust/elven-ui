# Elven UI

A Middle-earth themed, accessible React component library.

> 🚧 Work in progress — `0.1.0` is on the way.

## Themes (planned)

- **Rivendell** — light and airy
- **Lothlórien** — warm golden tones
- **Mirkwood** — dark

## Development

```bash
pnpm install
pnpm storybook   # component playground
pnpm test        # unit tests
pnpm build       # library build → dist/
```
